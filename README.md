# Nexgem-create-gateway

OmniVision Launch Interface. This web gateway connects frontend interfaces with API functionalities, built for rapid deployment and seamless navigation.

## 🚀 Live Demo

The project is actively deployed and hosted on Vercel:
* **Production URL:** [https://vercel.app](https://vercel.app)

---

## 📁 Repository Structure

* **`/api`** - Contains backend serverless functions, including the main logic generator (`generate.js`).
* **`index.html`** - The primary entry point and home page interface for the gateway.
* **`app.html`** - The main application dashboard interface featuring updated visual layer depths.
* **`vercel.json`** - Configuration file managing routes, rewrites, and deployment behaviors.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Hosting & Deployment:** Vercel

---

## 💻 Getting Started

### Prerequisites
To run this project locally, you only need a modern web browser. If you want to test the API functions locally, install the [Vercel CLI](https://vercel.com).

### Local Setup
1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the project directory:
   ```bash
   cd Nexgem-create-gateway
   ```
3. Open `index.html` directly in your browser, or run the Vercel development server:
   ```bash
   vercel dev
   ```
